Техническое задание
Описание
SmartBot это умный чат бот в формате виджета на сайте, который анализирует отклики кандидатов и автоматически задает уточняющие вопросы, если между данными из вакансии и резюме есть несоответствия.
Бот помогает работодателю быстро сузить аудиторию кандидатов и оставить только тех, кто реально подходит под требования вакансии.
После отклика кандидата открывается виджет прямо на сайте и показывает вопросы от бота в реальном времени.
Цель
Автоматизировать первичный отбор кандидатов и сократить ручную работу работодателя.
Бот должен самостоятельно анализировать отклики, задавать уточняющие вопросы и формировать оценку релевантности, чтобы работодатель сразу видел, кто подходит под вакансию.
Tone of Voice
Коммуникация чат бота должна быть дружелюбной, профессиональной и понятной.
Основные принципы:
1. Простота и ясность, без сложных фраз.
2. Вежливость и уважение к кандидату.
3. Нейтральность без давления.
4. Речь естественная и человечная.
5. Без шаблонных фраз и формальностей.
6. Эмпатичный подход при уточняющих вопросах.

Примеры правильных сообщений:
   * "Спасибо за отклик. Хочу уточнить, вы готовы работать в Алматы?"
   * "Вижу, что у вас чуть меньше опыта. Рассматриваете возможность обучения?"
"Благодарю за ответ, я учту эту информацию при анализе."
________________
Путь кандидата
   1. Отклик на вакансию
Кандидат оставляет отклик через форму на сайте. После отправки отклика открывается виджет чат бота с сообщением от системы.
   2. Первичный анализ
Искусственный интеллект сравнивает ключевые параметры из резюме и описания вакансии:
   * город
   * опыт работы
   * должность
   * образование
   * языки
   * зарплатные ожидания
   * формат занятости
   3. Диалог в виджете
Если есть расхождения, бот сразу задает уточняющий вопрос прямо на сайте.
Примеры сообщений:
   * "Вакансия в Алматы, вы готовы рассмотреть переезд?"
   * "Требуется опыт от трех лет, у вас полтора. Готовы рассматривать обучение?"
   * "Работа предполагает полный день, подходит ли вам такой график?"
   * Кандидат отвечает прямо в чате, ответы сохраняются в систему.
   4. Расчет релевантности
После диалога бот формирует процент соответствия кандидата вакансии и определяет причины несоответствий.
Примеры:
   * Подходит на 90 процентов, уточнение по опыту.
   * Не подходит, не готов к переезду.
   5. Сохранение данных
В профиле кандидата фиксируются:
   * процент релевантности
   * причины несоответствия
   * ответы из чата
   * текстовая выжимка для работодателя
Путь работодателя
   1. Работодатель публикует вакансию и задает ключевые критерии: город, опыт, формат, зарплата и другие.
   2. После отклика кандидата бот автоматически анализирует вакансию и резюме.
   3. В интерфейсе работодателя отображается:
   * список кандидатов с процентом релевантности
   * сводка причин, почему кандидат подходит или не подходит
   * возможность просмотреть переписку кандидата с ботом
   * фильтры по уровню релевантности
   * поиск по ответам кандидатов
Функциональные требования
Основной функционал
   * Интеграция чат бота в виде виджета на сайте
   * Автоматический анализ откликов и вакансий
   * Генерация уточняющих вопросов с помощью искусственного интеллекта
   * Сохранение ответов кандидатов
   * Расчет процента релевантности
   * Отображение диалогов в интерфейсе работодателя
   * Фильтрация кандидатов по уровню соответствия
Дополнительный функционал
   * Автоматическая категоризация причин несоответствий
   * Возможность задавать кастомные критерии отбора

Технологии
Frontend
   * Framework: React 17 или выше
   * UI: Mantine UI
   * State Management: На выбор
   * Интернационализация: react-i18next (опционально)
   * HTTP Client: Axios
   * Виджет: Standalone Web Component (iframe / script tag integration)
Backend
   * Framework (на выбор): 
   * FastAPI
   * Django
   * WebSocket (на выбор):
   * FastAPI WebSocket
   * Centrifugo
   * Django-Channels
   * Async задачи (опционально):
   * Background tasks (в FastAPI)
   * Taskiq
   * Celery
База данных:
   * Primary DB: PostgreSQL 15+
   * Cache: Redis
AI & ML:
   * LLM: gemini 1.5 flash – есть бесплатный лимит
   * Embeddings: OpenAI text-embedding-3-small (опционально)
   * Prompt Framework: LangChain (опционально)
DevOps & Infrastucture:
   * Контейнеризация: Docker + Docker Compose
   * Сервисы: Frontend, Backend, Postgres, Redis
   * Мониторинг:
   * Простой health check endpoint (опционально)
Безопасность:
   * Авторизация: JWT
   * CORS:
   * FastAPI CORS middleware
   * django-cors-headers
Методологии:
   * The Twelve-Factor App (опционально) 


Результат на демо
   * Кандидат откликается на вакансию на сайте
   * Сразу появляется чат бот, который задает уточняющие вопросы
   * Кандидат отвечает в реальном времени
   * Работодатель видит в системе кандидата с процентом релевантности и причинами отклонений
   * Показывается интерфейс, где можно фильтровать кандидатов и просматривать их диалоги
